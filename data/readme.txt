The data have been published in Hafting et al. (Nature, 2005). The files are in matlab format. They include spike and position times for a number of simultaneously recorded grid cells in layer II at the dorsocaudal pole of the medial entorhinal cortex while the rats were running in a cylinder with a diameter of 180 cm. 

Each file represents recordings from several cells in one brain location (from one hemisphere of one rat). The cell id is based on tetrode number and cell number (i.e: t2c7).

The first data set corresponds to the cells published in Supplementary Figure 2 of Hafting et al (the same cells as in Figure 2c and 2d). 

Recording depths: 
Tetrode 1-4: 500 um ventral to postrhinal border.
Tetrode 5-8:  20 um ventral to postrhinal border. 

In addition a data set from another rat from the same study is available. Recording depth: 280 um ventral to postrhinal border.
